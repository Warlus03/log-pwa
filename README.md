# log-pwa

決まった書式のテキストを貼ると項目に分けて保存し、日付順に並べて検索できるようにする、個人用の小さなPWA。

## つくり

- 単一ページ。依存ライブラリなし
- 保存は IndexedDB。データは端末の中だけに置かれ、サーバーには送られない
- Service Worker でオフライン動作
- Web Share Target（POST）で、他アプリの共有メニューから直接テキストを受け取る
  - GET ではなく POST にしているのは、共有された本文が URL に乗ってサーバー側に届くのを避けるため

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（画面・保存・検索すべて） |
| `manifest.json` | PWA 設定と共有先の登録 |
| `sw.js` | オフライン用キャッシュと共有の受け取り |
| `icon-*.png` | アイコン |

## 置きかた

1. このリポジトリの Settings → Pages で、Source を `main` のルートに設定
2. 表示された URL をスマートフォンの Chrome で開く
3. メニューから「ホーム画面に追加」

3 を行わないと、共有メニューに現れない。

## データ

設定画面から JSON で書き出し・読み込みができる。
ブラウザのデータは端末を変えると引き継がれないため、移行はこの書き出しファイルで行う。

## ライセンス

個人用。
